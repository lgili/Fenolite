Proofs of two kinds appear below. A task's **Proof** is a command an implementer runs in the iteration. Where a task also ends in scheduled runs of the nightly job, which nobody can run inside an iteration, it has a second line, **After the merge**, that the coordinator ticks from the runs; the task's box is ticked on the Proof, and the evidence label moves only on the second line. No task asks an agent for the full `make check`: it runs once, at the merge, by the coordinator.
