# Preserve floor refusals and prove qualified native upgrades

## Why

The literal versioned census records five original schematic formats below the published KiCad-8 read floor: one tag-10 row and four tag-9 rows. Refusing these original bytes is correct. It neither proves their electrical graph nor justifies claiming an original-source equality. The existing c0275 upgrade callback can invoke official CLI10 on private copies with tool/version and before/after digests.

The root coordinator approved a capability-aware evidence path: retain every original refusal, independently export its native old graph, upgrade verified copies through the existing callback, and require exact complete graph/name correspondence before qualifying the upgraded probe. No old-format parser, row filtering, accepted differences or original-status rewrite is proposed.

## What changes

Add explicit original-negative/native-original evidence and separately identified upgraded-copy census probes. Keep the declared source ref distinct from the running oracle major. Bridge the same checked originals across native9/native10 jobs using complete graph/name signatures and exact source/input/commit identities. A qualification such as `upgraded/equal` applies only to its successful proof chain, never to original bytes or full CAD fidelity. CI must retain every row and reject missing, mismatched or partial bridges.

The existing board-to-code production upgrade path is not widened speculatively. If an authored whole-project old-sheet control reproduces a production gap, add/review that focused task before production changes. Standalone hierarchical-label severity, visible label properties and other refusals stay independent.
