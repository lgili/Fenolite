# Design

The common CLI parser records whether `--kicad-version` was actually supplied (before or after the command). Append an optional defaultFalse internal Context flag; existing positional constructors and other commands retain behavior. Import uses ctx.kicad_target only when explicit, otherwise its existing supported source-major/default rule. One chosen target reaches both emit Options and the private self-check build. No canonical Design/model fields or source bytes change.

Existing project carrier validators still refuse KiCad10-only keys for9, including with allow-lossy. Plan argument digests retain the explicit option and target changes invalidate confirmation. Default9 imports retain byte-identical plans/payloads. The public CLI documentation already describes this flag as the written major; teach its import exception/default precisely and run guide generation because target behavior is public.

Authored controls use Fenolite's minimum-rule bench generated as KiCad9 with an authored project-only KiCad10 key. First demonstrate explicit10 fails before the fix; then prove explicit10 passes while default/explicit9 refuse. Prove flag order, default exact bytes and stale target plans. Public Coldfire new target10 recipe is a separate source-bound measurement; preserve historical/default refusal and any remaining full-proof failures.
