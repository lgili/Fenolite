Keep the existing `unconnected_name` spelling algorithm and unknown-character refusal. Add authored pin names `#`, `RESET#`, and a combination of already measured slash/space plus `#` to original hand-written naming controls. Measure actual exported net names on9.0.9 and10.0.6, both open and explicitly no-connect-marked. Record source/netlist hashes and tool version. If and only if those exact spellings match, add `#` to the measured allowed character set. No comparison, tolerance, model field, default class, native metadata or source data is changed.

An authored unit regression fails before the one-character extension. Unknown Unicode and parentheses remain unproved; defaults for existing measured names retain their complete bytes. Extend the existing naming character census so its guard requires an actual native probe for the new character. Public Video then receives a genuine new import10/full proof with strictL6 intact; original failing receipts are preserved.
