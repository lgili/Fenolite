## Decisions

1. Keep the c0225 boundary: CLI resolves the catalog; viewer accepts CatalogItem records and derives selection facts from their SymbolDef/FootprintDef. No catalog imports in view and no new renderer.
2. Symbol facts include exact pin numbers/names/types and reference prefix. Footprint facts include mounting kind, physical and distinct numbered-pad counts, pad sizes/centres in nm and minimum distance between distinct electrical pad centres. Use integer squared distances and isqrt; label it minimum centre spacing, rounded down by less than one nm, not manufacturer pitch. Missing spacing remains unknown. Generic geometry and matching counts do not establish compatibility.
3. The workspace offers text/family search, mounting kind, logical pad count and min/max centre-spacing and pad-size bounds in mm. Validate numeric filters and show empty results explicitly. Selection never silently substitutes a filtered-out part; changing a component clears mapping confirmation.
4. Two isolated preview frames open this same offline document at explicit library/item hashes, with controls hidden in preview mode. They reuse existing library scenes and canvas code, do not instantiate nested previews and do not communicate through BroadcastChannel. Same-origin/local URLs only, no network assets or generated CAD files.
5. Mapping starts empty. An explicit equal-number action may fill matching numbers, but does not confirm the map. Each symbol pin must name one or more existing numbered pads; numbers cannot be assigned to two pins, and every distinct nonempty footprint pad number must be covered. Empty mechanical pads are excluded. This validates structure only; a separate unchecked datasheet-review control gates the snippet. No inferred electrical equivalence is asserted.
6. Generate a Part constructor with explicit lib IDs, value and pad_map; validate/sanitize reference input and quote all strings. The snippet is a reusable component fragment, not a complete circuit. Copy/download is optional and does not edit a project. A clipboard failure leaves selectable code visible. Reset confirmation on every mapping or component change.
