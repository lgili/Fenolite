## view

`fenolite view [OPTIONS] PATH`

- `PATH`: a project file or folder, a board, sheet, library or drawing
- `--doc ID`: the document to show: id, path or name
- `--overlay FILE` (repeatable): draw an analyze reply or a findings file (JSON)
- `--serve`: serve on 127.0.0.1 until stopped
- `--port N` (default `8765`): with --serve: port (default 8765; 0 = any free)
- `--no-browser`: with --serve: no browser
- `--run-timeout SECONDS`: with --serve: time limit of a check the page runs (default 600)
- `--no-run`: with --serve: the page runs no check (recorded results only)
- `--allow-actions`, `--edit`: with --serve: the page can write the project's files through reviewed plans (fill, tidy, silk, test points, waivers, moves, exports, BOM); each write keeps a backup and can be undone
- `--export FILE`: write one standalone page
- `--cache {off,project,user}` (default `user`): scene cache
- `--docs ID,...`: --export only these
- `--variant NAME`: show an Altium project's variant
- `--compare OLD`: draw what changed since the board or sheet OLD
- `--check FILE|run`: draw the findings of a check, build or sync reply; run: check first
- `--roles FILE|run`: draw a roles --check reply on its board; run: run it first
- `--proposals FILE|run`: join a route --propose reply to its board; run: propose first (read-only)
- `--placement FILE`: draw a saved place --strategy optimize reply on its original board
- `--placement-request FILE`: with --serve: explicit scope for placement refinement and reviewed application
- `--report FILE` (repeatable): recorded convert/export JSON for project review; repeat for different commands
- `--select REF`: open at this part or net
- `--marks FILE`: review marks: list them; --serve saves new ones there
- `--theme THEME`: a KiCad colour theme: a .json file or a theme name
- `--no-review`: no review findings
- `--no-models`: no 3D models (gmsh)
- `--silk-gap MM`: silkscreen gap (default: the rule)
- `--mask-expansion MM` (default `0`): mask opening growth
