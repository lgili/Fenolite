## library

`fenolite library [OPTIONS] PATH`

- `PATH` (repeatable): a .kicad_pcb, .kicad_pro or project folder; or the action 'symbol' followed by pin tables, or 'generate' followed by package records
- `--out LIB.pretty`: the library folder to write, relative; for 'symbol', a relative .kicad_sym or .SchLib file; for 'generate', a relative folder
- `--diff LIBRARY`: a .pretty folder to compare with the board; writes nothing
- `--library NAME`: library name; required for seed (default: the stem of --out for 'symbol', Local for 'generate')
- `--positions N` (integer): 'generate' only: the one position count to draw of a connector series (default: every count)
- `--no-step`: 'generate' only: plan no .step model (the footprint keeps its path)
- `--no-pcblib`: 'generate' only: plan no Altium .PcbLib
- `--item PATH`: audit: check only this item folder, relative to ROOT
- `--base REF`: audit: a base tree (folder or git ref) for the version rules
- `--proof FILE`: audit with --item: gate this verify-source --json reply of the board (the proof job)
- `--version V`: release: the release version
- `--upstream DIR`: replay: use this upstream checkout instead of fetching
- `--keep DIR`: replay: keep the work folder here (must be missing or empty)
- `--with-current`: replay: run the fenolite steps with this Fenolite instead of the recorded version
- `--release DIR`: gallery: the folder of a release made by 'library release'
- `--renders DIR`: gallery: board views (top.svg, bottom.svg) and block schematics (schematic.svg) per item folder, with failures.json naming the ones that could not be made
- `--sheets DIR`: check: plan deterministic standalone HTML review sheets
- `--compare OLD`: check: compare records with this old tree or library
- `--fail-on {error,warning}` (default `error`): check: lowest finding severity that exits 5
- `--rules CODES`: check: run only these comma-separated library rule codes
- `--skip CODES`: check: omit these comma-separated library rule codes
- `--accept`: review: human acceptance of the current sheet
- `--revoke`: review: remove acceptance and restore previous evidence
- `--pin-content`: review: add the content digest to an older acceptance whose sheet bytes still match
- `--viewer DIR`: review --pin-content: viewer files (page.html, viewer.css, viewer.js) of the Fenolite that wrote the acceptance
- `--reviewer NAME`: review --accept: person who opened and checked the sheet
- `--sheet HEX`: review --accept: at least 12 hex digits of the current sheet SHA-256
- `--into DIR`: import/seed: output folder; import requires a project-relative path
- `--id NS:NAME`: import: device id (default Imported:<symbol>)
- `--symbol NAME`: import: select a source symbol, or a lib id without sources
- `--footprint NAME`: import: select a source footprint, or a lib id without sources
- `--prefer {altium,kicad}`: import: preferred source tool (default kicad)
- `--package NAME`: import: package record file or shipped id for comparison
- `--pin FUNCTION=PIN[:PAD[+PAD]]` (repeatable): import: pin-to-pad mapping
- `--manufacturer MANUFACTURER` (default ``): import: manufacturer
- `--mpn MPN` (default ``): import: manufacturer part number
- `--datasheet DATASHEET` (default ``): import: https:// URL; propose/review: local datasheet PDF
- `--ref-prefix REF_PREFIX` (default ``): import: reference prefix
- `--no-crosscheck`: import: skip the inferred package comparison
- `--from-librepcb DIR`: seed: local CC0-1.0 library checkout
- `--commit SHA`: seed: required full upstream commit
- `--namespace NS`: seed: item namespace (default FenoliteDevices)
- `--proposal FILE` (repeatable): propose: one or two cited parameter proposal files
- `--licence SPDX`: propose: record licence (default: see source terms)

## manifest

`fenolite manifest [OPTIONS] PATH`

- `PATH`: a .kicad_pcb, a .kicad_pro or a project folder
- `--artifacts DIR` (repeatable): a folder inside the project whose fenolite-artifacts.json lists artefacts to add (repeatable)
- `--stages A,B`: stages to run, of model.validate,circuit.rules,erc.kicad,copper.clearance,length.rules,topology.rules,placement.rules,roles.rules,zone.fill,drc.kicad,parity,schematic.drawn,netlist.assignment_compare,roundtrip,roundtrip.rt2,render (default: model.validate,circuit.rules,erc.kicad,copper.clearance,length.rules,topology.rules,placement.rules,roles.rules,zone.fill,drc.kicad,parity,schematic.drawn,netlist.assignment_compare,roundtrip)
- `--no-check`: run no stage: record hashes only
- `--verify`: compare the manifest with the files on disk; write nothing
- `-o`, `--out FILE`: the manifest file (default: fenolite-artifacts.json by the board)
- `--kicad-cli PATH`: the kicad-cli to run
- `--timeout SECONDS` (number, default `300.0`): kicad-cli timeout (300)

## mcp

`fenolite mcp [OPTIONS]`

- `--root DIR` (default `.`): the folder every call runs in and writes under
- `--read-only`: list only the commands that write nothing
- `--tools NAME,...`: list only these commands
- `--timeout SECONDS` (number, default `600.0`): stop a longer call
- `--list`: return the tools and resources; serve nothing
- `--allow-edit`: also serve fenolite_edit: a client that edits a design script and builds it runs code as you

## neighbors

## net

`fenolite net [OPTIONS] PATH [NAME]`

- `PATH`: a .kicad_pcb, a .kicad_pro or a project folder
- `NAME`: the net to describe (default: list all)
- `--islands`: with NAME: list each island of the net with its members
- `--without ITEM[,ITEM...]` (repeatable): with NAME: the islands without these tracks, arcs, vias or zones (id, native id or locator)

## netlist

`fenolite netlist [OPTIONS] PATH`

- `PATH`: a .kicad_sch, a .kicad_pcb, a .kicad_pro or a project folder
- `--source {fenolite,kicad}` (default `kicad`): kicad: kicad-cli sch export netlist (default); fenolite: read a generated sheet, no tool
- `--min-pins N` (integer, default `1`): leave out the nets with fewer pins (default 1: every net)
- `--kicad-cli PATH`: the kicad-cli to run
- `--timeout SECONDS` (number, default `300.0`): kicad-cli timeout (300)

## pads

`fenolite pads [OPTIONS] PATH [REF] [NUMBER]`

- `PATH`: a .kicad_pcb, a .kicad_pro or a project folder
- `REF`: only the pads of this part (path or reference)
- `NUMBER`: only the pads with this number
- `--origin X,Y` (default `0mm,0mm`): report positions relative to this point, two lengths with units (default 0mm,0mm)

## panel

`fenolite panel [OPTIONS] --out DIR --target {10,9,altium} PANEL.py`

- `PANEL`: the panel script (run in-process)
- `--out DIR`: the output folder
- `--target {10,9,altium}`: KiCad major or altium
- `--altium-panel {auto,embedded,flat}`: the Altium form (default auto)
- `--altium-pour {computed,outline}`: with --target altium: computed pours the polygons with Altium's rules (default, experimental; needs the geo extra, without which the default writes the outline with a warning), outline writes them unpoured
- `--discard-layout`: replace files edited since

## parity

`fenolite parity [OPTIONS] PATH`

- `PATH`: a .kicad_pcb, a .kicad_pro or a project folder; an Altium .PrjPcb, project folder or .PcbDoc
- `--netlist {auto,kicad,own}` (default `auto`): where the nets of the schematic come from. auto (default): Fenolite's own reading of a schematic it generated, else kicad-cli; own: never a tool; kicad: always kicad-cli
- `--kicad-cli PATH`: the kicad-cli to run
- `--timeout SECONDS` (number, default `300.0`): kicad-cli timeout (300)

## path

`fenolite path [OPTIONS] --net NET --from A --to B PATH`

- `PATH`: a .kicad_pcb or a .PcbDoc
- `--net NET`: the net to route
- `--from A`: REF-PIN or X,Y@LAYER (mm)
- `--to B`: REF-PIN or X,Y@LAYER (mm)
- `--width W`: search one connection of this track width (mm)
- `--widest`: measure the widest track that fits; never writes
- `--layers L1,L2`: the copper layers a track may use
- `--grid G` (default `0.1mm`): the search grid (default 0.1mm)
- `--max-states N` (integer, default `200000`): search state bound
- `--max-vias N` (integer): default 2, 0 with --widest
- `--resolution R`: channel bracket (default 10um)
- `--pours {kept,refilled}`: kept (.PcbDoc) or refilled (.kicad_pcb)
- `--timeout S` (number): seconds for the command
- `--gate {clone}`: open the clone gate of a .PcbDoc
- `-o`, `--out FILE`: write to this file instead of replacing PATH

## pick

`fenolite pick [OPTIONS] PATH`

- `PATH`: a design script, or its folder (design.py in it)
- `--candidates COMPONENT`: rank the rows of one query part (read-only)
- `--update COMPONENT` (repeatable): re-resolve the pick of this part against the current catalog (repeatable)
- `--update-all`: re-resolve every pick
- `--propose QUERY`: write UNVERIFIED rows that meet QUERY under devices/proposed/ (never the lock)
- `--from FILE`: the CSV or JSON rows to propose
- `--supplier NAME`: a plugin of the group fenolite.suppliers
- `--allow-offsite`: allow a supplier plugin that sends data off this machine
- `--timeout SECONDS` (number): total supplier lookup timeout (above zero, at most 300; default 30)
