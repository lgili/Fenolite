# Command arguments, part 3

This page is generated by `tools/gen_agent_guide.py`: do not edit it, change the code and run the tool.

Back to [the command index](commands.md).

## edit

`fenolite edit [OPTIONS] PATH`

- `PATH`: a *.py, a *.toml, an fp-lib-table, a sym-lib-table or an Altium *.PcbDoc
- `--content-file FILE`: a file holding the whole new text
- `--edits-file FILE`: a JSON list of {"old": ..., "new": ...} pairs
- `--ops-file FILE`: a *.PcbDoc only: a JSON list of {"op": ..., "item": {...}, ...} operations, or a result.edit_plan
- `--gate NAME` (repeatable): a *.PcbDoc only: open the edit session's gate NAME for this run (UNVERIFIED; repeatable)

## equivalent

`fenolite equivalent [OPTIONS] A [B]`

- `A`: a KiCad board, project file, folder or root schematic, an Altium document or project, or a .fenolite/ folder of a built design
- `B`: the design to compare with A
- `--level N`: run the levels 1 to N, N of 1 to 8, or S for the drawn schematics (default: the highest available of 1 to 5)
- `--strict`: level 5 also matches every track, arc and via item by item
- `--pixel-ppm N` (integer, default `1000`): level 8: the differing pixels a layer may hold, in ppm of its inked pixels (default 1000)
- `--render-pitch-um N` (integer, default `50`): level 8: the pixel pitch of a board layer in micrometres (default 50)
- `--tolerance-nm N` (integer): length tolerance per coordinate
- `--tolerance-udeg N` (integer): angle tolerance in microdegrees
- `--tolerance-ppm N` (integer): tolerance of a routed length of level 5, in parts per million of the length
- `--frame {absolute,relative}`: relative removes one translation (default absolute)
- `--ignore-ref GLOB` (repeatable): leave out matching references
- `--exclusions FILE`: an exclusion file (TOML); needs --profile
- `--profile NAME`: the profile of --exclusions to apply
- `--against {kicad-import}`: compare A with kicad-cli's own import of it (needs kicad-cli 10)
- `--kicad-cli PATH`: the kicad-cli of --against
- `--timeout SECONDS` (number, default `300.0`)

## export

`fenolite export [OPTIONS] -o DIR PATH`

- `PATH`: a .kicad_pcb, a .kicad_pro or a project folder
- `-o`, `--out DIR`: the folder to write under
- `--gerbers`: Gerber files and the job file
- `--drill`: Excellon drill files (PTH and NPTH)
- `--pos`: component positions (CSV, mm)
- `--ipcd356`: IPC-D-356 netlist
- `--ipc2581`: IPC-2581 (version C, mm), one XML file
- `--odb`: ODB++, one zip file
- `--step`: STEP model with the 3D models Fenolite locates
- `--pdf`: board PDF, one file per layer
- `--dxf`: DXF (mm), one file per mechanical layer
- `--sch-pdf`: schematic PDF, every sheet of the hierarchy
- `--all`: the four fabrication kinds (Gerbers, drill, positions, netlist)
- `--altium-rul`: the project's rules as an Altium rule file (no tool runs; not part of --all)
- `--fab-drawing`: a fabrication drawing (PDF) with KiCad's drill maps and report (not part of --all)
- `--assembly-drawing`: assembly drawings (PDF), top and bottom (not part of --all)
- `--drawing-spec FILE`: a TOML file of paper, sheet, tables, notes and assembly options for the drawing kinds
- `--manifest`: also add the files to fenolite-artifacts.json in DIR
- `--preset FILE`: a TOML file of your fabrication options for the Gerber, drill and position exports
- `--readback`: read the Gerber, drill and position files back and compare them with the board before anything is written (export.readback-*)
- `--kicad-cli PATH`: the kicad-cli to run
- `--timeout SECONDS` (number, default `300.0`): per kicad-cli run (300)

## family

- `FAMILY_ACTION` (one of `decode`, `encode`, `expand`, `lint`, `list`, `show`): what to do

## fill

`fenolite fill [OPTIONS] PATH`

- `PATH`: a .kicad_pcb, .kicad_pro or project folder
- `--from REFILLED`: a board already refilled by KiCad
- `-o`, `--out FILE`: write to this file instead of replacing PATH's board
- `--kicad-cli PATH`: KiCad 10 binary or docker:<image>
- `--timeout SECONDS` (number, default `300.0`)

## get

`fenolite get [OPTIONS] [KIND] [ID]`

- `KIND`: the item kind: symbol, footprint, device, block, board
- `ID`: the item id: <Namespace>:<name>, or <source>/<name> for a board
- `--version V`: the item version (default: the release's)
- `--release R`: the library release to read
- `--script FILE`: the design script whose folder receives items (default design.py)
- `--into DIR`: board: the folder to create (default ./<name>), missing or empty
- `--from SRC`: a release folder, a fenolite-library checkout, or a file:// git URL (#ref)
- `--offline`: open no connection; use the cache or --from only
- `--index-sha256 HEX`: the SHA-256 of a release index this version does not list
- `--accept-licence SPDX[,SPDX...]` (repeatable): accept these licences of the planned items (needed for any id but CC0-1.0)
- `--list`: list the items of a cached index
- `--search TEXT`: search ids, titles, summaries and tags of a cached index
- `--status`: report the pinned items: present, modified, newer
- `--locked SCRIPT`: restore every pinned item whose folder is missing
- `--remove`: with KIND ID: remove a vendored item and its pin
- `--refresh`: download one release index into the cache
- `--kind K`: --list, --search: only this kind
- `--licence ID|FAMILY`: --list, --search: only this SPDX id or family
- `--frozen`: refused: get changes the lock (exit 2)

## import

`fenolite import [OPTIONS] --to {python} --out DIR PATH`

- `PATH`: a .kicad_pro, .kicad_pcb, .kicad_sch, .PrjPcb or .PcbDoc
- `--to {python}`: the target: python (the Fenolite DSL)
- `--out DIR`: the project folder to write
- `--name NAME`: the design name; default: the project's stem
- `--licence SPDX`: the upstream licence as an SPDX expression
- `--copyright TEXT` (repeatable): an upstream copyright holder
- `--source URL`: where the upstream board lives
- `--revision REV`: the upstream revision imported
- `--licence-file FILE` (repeatable): an upstream LICENSE, NOTICE or COPYING file, copied unchanged
- `--adopt`: also write adopted/: the source board with the identities a build derives
- `--no-upgrade`: refuse a file below the read floor
- `--no-verify`: skip the self-check build

## init

`fenolite init [OPTIONS] DIR`

- `DIR`: the project folder; it is created when missing
- `--starter NAME` (default `blink`): the starter to write (blink)
- `--name NAME`: the design name (default: the last part of DIR)
- `--force`: replace an existing DIR/design.py

## inspect

`fenolite inspect [OPTIONS] FILE`

- `FILE`: a KiCad board, footprint, symbol library, schematic or sheet; or an Altium document, library or project file
- `--summary`: header and counts (the default view)
- `--streams`: list storages and streams in an MS-CFB file
- `--blocks`: the block ids, versions and instances of a design lock or a built .fenolite/circuit.json
- `--limit-bytes N`: maximum compound-file size

## kit

`fenolite kit [OPTIONS] {build,record,status,verify} [DIR]`

- `ACTION` (one of `build`, `record`, `status`, `verify`): what to do with the kit
- `FOLDER`: verify, record: the kit folder after a run
- `-o`, `--out DIR`: build: the folder to write the kit into; record: the repository that gets the run record
- `--samples DIR`: build, status: the folder of the sample scripts (default: examples/kit of the source checkout)
- `--repo DIR`: status: the repository to read (default: this folder)
