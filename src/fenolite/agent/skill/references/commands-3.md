# Command arguments, part 3

## get

`fenolite get [OPTIONS] [KIND] [ID]`

- `KIND`: the item kind: symbol, footprint, device, block, board
- `ID`: the item id: <Namespace>:<name>, or <source>/<name> for a board
- `--version V`: the item version (default: the release's)
- `--release R`: the library release to read
- `--script FILE`: the design script whose folder receives items (default design.py)
- `--into DIR`: board: the folder to create (default ./<name>), missing or empty
- `--from SRC`: a release folder, a fenolite-library checkout, or a file:// git URL (#ref)
- `--offline`: open no connection; use the cache or --from only
- `--index-sha256 HEX`: the SHA-256 of a release index this version does not list
- `--accept-licence SPDX[,SPDX...]` (repeatable): accept these licences of the planned items (needed for any id but CC0-1.0)
- `--list`: list the items of a cached index
- `--search TEXT`: search ids, titles, summaries and tags of a cached index
- `--status`: report the pinned items: present, modified, newer
- `--locked SCRIPT`: restore every pinned item whose folder is missing
- `--remove`: with KIND ID: remove a vendored item and its pin
- `--refresh`: download one release index into the cache
- `--kind K`: --list, --search: only this kind
- `--licence ID|FAMILY`: --list, --search: only this SPDX id or family
- `--frozen`: refused: get changes the lock (exit 2)

## impedance

`fenolite impedance [OPTIONS] PATH`

- `PATH`: a .kicad_pcb, a .kicad_pro or a project folder
- `--estimate`: add the estimates of single-ended microstrip and stripline rows (INFERRED)
- `-o`, `--out FILE`: also write the table as a CSV file

## import

`fenolite import [OPTIONS] --to {python} --out DIR PATH`

- `PATH`: a .kicad_pro, .kicad_pcb, .kicad_sch, .PrjPcb or .PcbDoc
- `--to {python}`: the target: python (the Fenolite DSL)
- `--out DIR`: the project folder to write
- `--name NAME`: the design name; default: the project's stem
- `--licence SPDX`: the upstream licence as an SPDX expression
- `--copyright TEXT` (repeatable): an upstream copyright holder
- `--source URL`: where the upstream board lives
- `--revision REV`: the upstream revision imported
- `--licence-file FILE` (repeatable): an upstream LICENSE, NOTICE or COPYING file, copied unchanged
- `--adopt`: also write adopted/: the source board with the identities a build derives
- `--no-upgrade`: refuse a file below the read floor
- `--no-verify`: skip the self-check build

## init

`fenolite init [OPTIONS] DIR`

- `DIR`: the project folder; it is created when missing
- `--starter NAME` (default `blink`): the starter to write (blink)
- `--name NAME`: the design name (default: the last part of DIR)
- `--force`: replace an existing DIR/design.py

## inspect

`fenolite inspect [OPTIONS] FILE`

- `FILE`: a KiCad board, footprint, symbol library, schematic or sheet; or an Altium document, library or project file
- `--summary`: header and counts (the default view)
- `--streams`: list storages and streams in an MS-CFB file
- `--blocks`: the block ids, versions and instances of a design lock or a built .fenolite/circuit.json
- `--limit-bytes N`: maximum compound-file size

## kit

`fenolite kit [OPTIONS] {build,record,status,verify} [DIR]`

- `ACTION` (one of `build`, `record`, `status`, `verify`): what to do with the kit
- `FOLDER`: verify, record: the kit folder after a run
- `-o`, `--out DIR`: build: the folder to write the kit into; record: the repository that gets the run record
- `--samples DIR`: build, status: the folder of the sample scripts (default: examples/kit of the source checkout)
- `--repo DIR`: status: the repository to read (default: this folder)

## library

`fenolite library [OPTIONS] PATH`

- `PATH` (repeatable): a .kicad_pcb, .kicad_pro or project folder; or the action 'symbol' followed by pin tables, or 'generate' followed by package records
- `--out LIB.pretty`: the library folder to write, relative; for 'symbol', a relative .kicad_sym or .SchLib file; for 'generate', a relative folder
- `--diff LIBRARY`: a .pretty folder to compare with the board; writes nothing
- `--library NAME`: 'symbol' and 'generate' only: the library name (default: the stem of --out for 'symbol', Local for 'generate')
- `--positions N` (integer): 'generate' only: the one position count to draw of a connector series (default: every count)
- `--no-step`: 'generate' only: plan no .step model (the footprint keeps its path)
- `--no-pcblib`: 'generate' only: plan no Altium .PcbLib
- `--item PATH`: audit: check only this item folder, relative to ROOT
- `--base REF`: audit: a base tree (folder or git ref) for the version rules
- `--proof FILE`: audit with --item: gate this verify-source --json reply of the board (the proof job)
- `--version V`: release: the release version
- `--upstream DIR`: replay: use this upstream checkout instead of fetching
- `--keep DIR`: replay: keep the work folder here (must be missing or empty)
- `--with-current`: replay: run the fenolite steps with this Fenolite instead of the recorded version
- `--release DIR`: gallery: the folder of a release made by 'library release'

## manifest

`fenolite manifest [OPTIONS] PATH`

- `PATH`: a .kicad_pcb, a .kicad_pro or a project folder
- `--artifacts DIR` (repeatable): a folder inside the project whose fenolite-artifacts.json lists artefacts to add (repeatable)
- `--stages A,B`: stages to run, of model.validate,circuit.rules,erc.kicad,copper.clearance,length.rules,placement.rules,roles.rules,zone.fill,drc.kicad,parity,schematic.drawn,netlist.assignment_compare,roundtrip,roundtrip.rt2,render (default: model.validate,circuit.rules,erc.kicad,copper.clearance,length.rules,placement.rules,roles.rules,zone.fill,drc.kicad,parity,schematic.drawn,netlist.assignment_compare,roundtrip)
- `--no-check`: run no stage: record hashes only
- `--verify`: compare the manifest with the files on disk; write nothing
- `-o`, `--out FILE`: the manifest file (default: fenolite-artifacts.json by the board)
- `--kicad-cli PATH`: the kicad-cli to run
- `--timeout SECONDS` (number, default `300.0`): kicad-cli timeout (300)

## mcp

`fenolite mcp [OPTIONS]`

- `--root DIR` (default `.`): the folder every call runs in and writes under
- `--read-only`: list only the commands that write nothing
- `--tools NAME,...`: list only these commands
- `--timeout SECONDS` (number, default `600.0`): stop a longer call
- `--list`: return the tools and resources; serve nothing
- `--allow-edit`: also serve fenolite_edit: a client that edits a design script and builds it runs code as you

`fenolite netlist [OPTIONS] PATH`

## panel

`fenolite panel [OPTIONS] --out DIR --target {10,9,altium} PANEL.py`

- `PANEL`: the panel script (run in-process)
- `--out DIR`: the output folder
- `--target {10,9,altium}`: KiCad major or altium
- `--altium-panel {auto,embedded,flat}`: the Altium form (default auto)
- `--altium-pour {computed,outline}`: with --target altium: computed pours the polygons with Altium's rules (default, experimental; needs the geo extra, without which the default writes the outline with a warning), outline writes them unpoured
- `--discard-layout`: replace files edited since

## parity

`fenolite parity [OPTIONS] PATH`

- `PATH`: a .kicad_pcb, a .kicad_pro or a project folder; an Altium .PrjPcb, project folder or .PcbDoc
- `--netlist {auto,kicad,own}` (default `auto`): where the nets of the schematic come from. auto (default): Fenolite's own reading of a schematic it generated, else kicad-cli; own: never a tool; kicad: always kicad-cli
- `--kicad-cli PATH`: the kicad-cli to run
- `--timeout SECONDS` (number, default `300.0`): kicad-cli timeout (300)

## pick

`fenolite pick [OPTIONS] PATH`

- `PATH`: a design script, or its folder (design.py in it)
- `--candidates COMPONENT`: rank the rows of one query part (read-only)
- `--update COMPONENT` (repeatable): re-resolve the pick of this part against the current catalog (repeatable)
- `--update-all`: re-resolve every pick
- `--propose QUERY`: write UNVERIFIED rows that meet QUERY under devices/proposed/ (never the lock)
- `--from FILE`: the CSV or JSON rows to propose
- `--supplier NAME`: a plugin of the group fenolite.suppliers
- `--allow-offsite`: allow a supplier plugin that sends data off this machine
