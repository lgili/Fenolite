## route

`fenolite route [OPTIONS] --router NAME PATH`

- `PATH`: a .kicad_pcb, .kicad_pro or project folder
- `--router NAME`: registered routing plugin
- `--nets GLOB` (repeatable): net-name pattern (repeatable)
- `--rip`: remove the copper of the matching nets before routing; locked and script copper stay
- `--include-zone-nets`: route nets that also have copper zones
- `--no-plane-fanout`: do not join the SMD pads of plane nets to their planes with fan-out vias before routing
- `--require-complete`: exit 5 and write nothing when a selected net still has an open connection
- `--router-path PATH`: KiCadRoutingTools checkout, or the Freerouting jar (docker:<image> runs a container)
- `--router-python PATH`: Python interpreter for the external router
- `--requirements FILE`: user requirements TOML for opt-in search proposals and decisions
- `--router-option KEY=VALUE` (repeatable): router-specific option
- `--order GLOBS` (repeatable): route the matching nets first (repeatable: one tier per value, globs separated by commas; the other nets last)
- `--timeout SECONDS` (number): time budget of the whole routing step (default: the router's own, 900 s for the external routers); the copper of the router runs that finished in time is kept
- `--allow-offsite`: allow a router that sends design data off this machine
- `--escape REF[=grid|perimeter]` (repeatable): escape the pads of the matching parts before routing, with a router that has the escape feature (repeatable; the kind is found from the pads unless given)
- `--pairs-as-nets`: route the nets of differential pairs as single nets, uncoupled, with any router
- `-o`, `--out FILE`: write the routed board to this file
- `--roles {critical}`: route the critical connections of the confirmed gate loops and Kelvin pairs (role mode)
- `--group NAME` (repeatable): with --roles: route this role group only (repeatable)
- `--roles-file FILE`: with --roles: the role document to read
- `--propose`: list every open connection with candidate shapes and their facts, no score; writes nothing
- `--propose-with ROUTER` (repeatable): also generate reviewed candidates with a supported local external router (repeatable)
- `--accept ID` (repeatable): lock this candidate (repeatable; plan)
- `--reject ID` (repeatable): remember a rejected candidate or proposal (repeatable; plan)
- `--reason TEXT`: with --reject: why, one line
- `--replay BUNDLE`: replay all locked decisions, or one atomic bundle
- `--forget ID` (repeatable): drop a decision and its copper (repeatable)
- `--kind {connection,fanout,group,join,role-net}` (repeatable): filter proposal/decision subjects by kind (repeatable)
- `--candidates N` (integer): internal candidates per subject, 1 to 8 (default 4); --propose-with adds external alternatives
- `--show-rejected`: with --propose: list rejected candidates too
- `--gate {drc}`: drc: judge the edit with kicad-cli DRC and write it without the items that bring new findings
- `--kicad-cli PATH`: kicad-cli binary or docker:<image> for --gate

## silk

`fenolite silk [OPTIONS] PATH`

- `PATH`: a .kicad_pcb, .kicad_pro or project folder
- `--designators`: place the Reference text of every part
- `--clip`: cut the silkscreen strokes at mask openings and pad holes (first)
- `--margin LENGTH`: with --clip, the gap from a stroke to an opening (default: the silk_clearance rule, else 0)
- `--keep`: move only designators that meet an obstacle
- `--refs GLOB` (repeatable): place only matching references (repeatable)
- `--sizes LENGTHS`: text heights to try (default: the field's, then the board's least text height)
- `--angles LIST` (default `0,90`): board angles to try: 0, 90 or 0,90
- `--clearance LENGTH`: least distance from a designator to anything else (default 0.15mm)
- `--gap LENGTH`: distance from the part's courtyard to its designator (default 0.1mm)
- `--measure {auto,estimate,kicad}` (default `auto`): text ink: rendered by kicad-cli (kicad), from the glyph table (estimate), or kicad when found
- `-o`, `--out FILE`: write to this file instead of replacing PATH's board
- `--drc`: run kicad-cli DRC on the board before and after
- `--kicad-cli PATH`: kicad-cli binary or docker:<image>
- `--timeout SECONDS` (number, default `300.0`)

## sync

`fenolite sync [OPTIONS] --out DIR DESIGN.py`

- `DESIGN`: the design script (executed in-process)
- `--out DIR`: the built project folder to read
- `--target {altium,kicad}` (default `kicad`): the backend to synchronise (default kicad)
- `--to-source`: the direction: from the board in DIR to the files beside DESIGN.py (required)
- `--check`: write nothing; report each file that would change as an error (for CI)
- `--take SIDE[:TARGET]` (repeatable): refused: sync records and never resolves; resolve a conflict with fenolite build --take
- `--freeze-schematic`: also write schematic.toml beside DESIGN.py from the project's generated schematic (KiCad only); add design.load_schematic('schematic.toml') to draw the sheets from it

## template

`fenolite template [OPTIONS] --target {altium,kicad} -o OUT {build,import} FILE`

- `ACTION` (one of `build`, `import`): build a specification, or import an Altium template
- `SPEC`: SPEC, the *.sheet.toml specification (build); SRC, the .SchDot or .SchDoc file (import)
- `--target {altium,kicad}`: the backend to write for
- `-o`, `--out OUT`: the drawing-sheet file to write
- `--size NAME`: build --target altium: the size of the template, one of the sizes the specification lists (default: the first); a usage error otherwise
- `--altium-format {ascii,binary}`: build --target altium: the form of the template, binary (default) or ascii; a usage error otherwise

## testpoints

`fenolite testpoints [OPTIONS] PATH`

- `PATH`: a .kicad_pcb, a .kicad_pro or a project folder
- `--side {both,bottom,top}` (default `both`): the side a probe comes from (default both)
- `--template FILE`: the template whose [placement] frame the CSV file uses
- `--min-coverage PERCENT`: an error below this share of covered nets (0 to 100)
- `--min-pitch LENGTH`: an error for two test points closer than this (1.27mm)
- `--min-fiducials N`: an error for a side with parts and fewer global fiducials
- `-o`, `--out FILE`: also write the report as a CSV file
- `--place`: add a probe and its track for each net --side does not reach
- `--grid LENGTH`: with --place, the grid of probe sites (2.54mm)
- `--reach LENGTH`: with --place, the farthest site from the net (5mm)
- `--size LENGTH`: with --place, the probe pad's diameter (1mm)
- `--nets GLOB` (repeatable): with --place, only these nets (repeatable)
- `--drc`: with --place, kicad-cli DRC before and after
- `--kicad-cli PATH`: kicad-cli binary or docker:<image> for --drc
- `--manifest`: also add FILE to fenolite-artifacts.json in its folder

## tidy

`fenolite tidy [OPTIONS] PATH`

- `PATH`: a .kicad_pcb, .kicad_pro or project folder
- `--nets GLOB` (repeatable): tidy only matching nets (repeatable)
- `--prune`: remove dangling tracks, arcs and vias
- `--straighten`: redraw runs of tracks with fewer turns
- `--chamfer`: chamfer right-angle joints and T-joints
- `--zones`: with the chamfer: also cut zone corners
- `--leg LENGTH`: the leg of a chamfer (default: twice the track width)
- `-o`, `--out FILE`: write to this file instead of replacing PATH's board
- `--drc`: run kicad-cli DRC on the board before and after
- `--kicad-cli PATH`: kicad-cli binary or docker:<image> for --drc
- `--timeout SECONDS` (number, default `300.0`)
- `--gate {drc}`: drc: judge the edit with kicad-cli DRC and write it without the items that bring new findings
- `--report`: write nothing; report the routing style
- `--compare REFERENCE`: also report this KiCad board (implies --report)

## verify-source

`fenolite verify-source [OPTIONS] --against ORIGINAL SCRIPT`

- `SCRIPT`: the design script (executed in-process, as build does)
- `--against ORIGINAL`: the original: a KiCad project folder or .kicad_pro or .kicad_pcb, or an Altium .PrjPcb
- `--levels SPEC`: the levels to run, e.g. 1-7,S,8 (default: all)
- `--tolerance-nm N` (integer): length tolerance per coordinate
- `--tolerance-udeg N` (integer): angle tolerance in microdegrees
- `--tolerance-ppm N` (integer): tolerance of a routed length (ppm)
- `--frame {absolute,relative}`: relative removes one translation (default absolute)
- `--pixel-ppm N` (integer): level 8 pixel tolerance (default 1000)
- `--render-pitch-um N` (integer): level 8 pixel pitch (default 50)
- `--provenance FILE`: the provenance file (default: PROVENANCE.json beside SCRIPT)
- `--record`: write fidelity.proof to the provenance file
- `--accept KEY` (repeatable): accept the difference <level>:<kind>:<where>
- `--reason TEXT` (repeatable): why --accept accepts
- `--target {9,10}` (integer): the KiCad major to build for
- `--upgrade`: upgrade a copy of an older original (kicad-cli)
- `--copper-check {refuse,warn}`: the copper guard of the build: refuse or warn (default: warn for a copy, which the import record of the provenance file marks, else refuse)
- `--kicad-cli PATH`: the kicad-cli of --upgrade or a derived padvia cache proof (KiCad 10)
- `--timeout SECONDS` (number, default `300.0`)
