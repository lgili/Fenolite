## build

`fenolite build [OPTIONS] --out DIR DESIGN.py`

- `DESIGN`: the design script (executed in-process)
- `--out DIR`: the project folder to write
- `--altium-template FILE.SchDot`: apply a native binary sheet template to every Altium schematic, preserving page settings, fonts and embedded images; requires binary Altium output and no drawing_sheet in the script
- `--discard-layout`: replace outputs changed since the last build (backups kept)
- `--lock FILE`: the design lock to read and write, in place of <script stem>.lock beside the script
- `--frozen`: refuse with exit 7 (FEN-7004) when the design lock would change, or a --take or a CAD edit not in edits.toml would be kept; never write the lock
- `--take SIDE[:TARGET]` (repeatable): resolve a sync.conflict: SIDE is code, cad, board or schematic, TARGET a component path or PATH#PROPERTY (every conflict without one); repeatable
- `--target {altium,kicad}` (default `kicad`): kicad (default), or altium: an experimental Altium project file and schematic instead
- `--altium-format {ascii,binary}`: the form of the Altium schematic with --target altium: binary (default, Altium's own) or ascii; a usage error with --target kicad (default form: binary)
- `--altium-sheets {flat,modules}`: the sheets of the Altium schematic with --target altium: flat (default, one sheet) or modules (a top sheet with sheet symbols and one sheet per top-level module, with ports, sheet entries and signal harnesses); a usage error with --target kicad (default: flat)
- `--altium-outjob {off,on}`: with --target altium: on (default) writes <name>.OutJob, an output job with Gerber, NC drill, pick-and-place, bill-of-materials, schematic-print and PCB-print outputs, when the build writes a PCB document; off writes none; a usage error with --target kicad
- `--altium-outjob-preset FILE`: the export preset (the TOML file of export --preset) the output job is made for: its gerbers.precision is the decimals of the job's Gerber settings (result.outjob.gerber), and its other options are listed in result.outjob.defaults, to be set in Altium; a usage error with --target kicad or with --altium-outjob off
- `--altium-draftsman {off,on}`: with --target altium: on requests a Draftsman document; off (default) keeps legacy files. The native gate is closed (route P): on writes the title-block fields as project parameters for a document made from an Altium template
- `--drawing-spec FILE`: fenolite.drawing-spec.v0 TOML for --target altium --altium-draftsman on
- `--altium-symbols {generic,graphics}`: with --target altium: graphics (default) draws each resolved symbol from its own graphics, generic draws one rectangle per part (the output of 0.2.0 and earlier); a usage error with --target kicad (default: graphics)
- `--altium-directions {off,on}`: with --target altium: on (default) gives each port and sheet entry the I/O type that follows from the pin types on its net, off leaves them all unspecified; a usage error with --target kicad (default: on)
- `--altium-bodies {extruded,off}`: with --target altium: extruded writes the extruded component bodies of the board's footprints (experimental), off writes none and reports each body, as earlier versions did; a usage error with --target kicad (default: extruded)
- `--altium-pour {computed,outline}`: with --target altium: computed writes the poured copper of each polygon as Fenolite computes it with Altium's rules (experimental; needs the geo extra, without which the default writes the outline with a warning), outline writes the polygons unpoured, as earlier versions did; a usage error with --target kicad (default: computed)
- `--copper-from BOARD.kicad_pcb`: with --target altium: copy the tracks, arcs, vias and zones of a routed KiCad board of the same design into the PCB document, after checking that the board matches the design; the board's placements win; a usage error with --target kicad
- `--copper-check {refuse,warn}`: what a short or a clearance error in the copper of the board about to be written does: refuse (default; exit 5, nothing written) or warn (reported as warnings, files written); with --target altium only a short refuses, and a clearance error is reported as a warning
- `--vendor {all,project}` (default `all`): all: copy the placed footprints of every library into DIR/lib/ (the copies keep their library's licence); project: copy only those of project tables
- `--schematic {skip,write}`: write (default): also write DIR/<name>.kicad_sch, its symbol libraries under DIR/lib/ and sym-lib-table, and name the pads of unconnected pins as KiCad does; skip: write the board without a schematic; a usage error with --target altium
- `--schematic-layout {grid,readable,wired}`: wired (default): one sheet per module under DIR/sheets/, local connections drawn as wires, supplies as power symbols and one label per drawn group of a net; readable: one sheet per module, and 2-pin parts beside the IC pins they connect to, joined by a wire; grid: one flat sheet with a label on every pin, the form of v0.2a; a usage error with --target altium
- `--altium-layout {blocks,grid}`: Altium arrangement: grid preserves legacy layout; blocks composes functional blocks

## catalog

`fenolite catalog [OPTIONS] {import,list,show,view} [lib_id]`

- `CATALOG_ACTION` (one of `import`, `list`, `show`, `view`): list entries, show one ID, export a browser, or import a device template from a symbol and a footprint
- `LIB_ID`: catalog ID required by show
- `--kind {device,family,footprint,symbol}`: list or show only this kind; show takes it when a device id equals a symbol or footprint id
- `--query QUERY`: case-insensitive search in id, category and summary
- `--out FILE`: required by view (a standalone HTML browser) and by import (the device TOML to write)
- `--symbol LIB:SYM`: import: the symbol the device joins
- `--footprint LIB:FP`: import: the footprint the device joins
- `--id NS:NAME`: import: the id of the device
- `--pin FUNCTION=PIN[:PAD[+PAD]]` (repeatable): import: put symbol pin PIN in FUNCTION, on the given pads (default: the pad of its number)
- `--manufacturer MANUFACTURER` (default ``): import: the manufacturer, printable text
- `--mpn MPN` (default ``): import: the manufacturer part number, printable text
- `--datasheet DATASHEET` (default ``): import: an https:// URL
- `--ref-prefix REF_PREFIX` (default ``): import: the reference prefix

## check

`fenolite check [OPTIONS] PATH`

- `PATH`: a .kicad_pcb, a .kicad_pro or a project folder; an Altium document, .PrjPcb or project folder
- `--stages A,B`: stages to run, of model.validate,circuit.rules,erc.kicad,copper.clearance,length.rules,topology.rules,placement.rules,roles.rules,zone.fill,drc.kicad,parity,schematic.drawn,netlist.assignment_compare,roundtrip,roundtrip.rt2,render (default: model.validate,circuit.rules,erc.kicad,copper.clearance,length.rules,topology.rules,placement.rules,roles.rules,zone.fill,drc.kicad,parity,schematic.drawn,netlist.assignment_compare,roundtrip); for Altium input, of model.validate,circuit.rules,erc.lite,copper.clearance,placement.rules,roles.rules,parity,netlist.assignment_compare,roundtrip.rta0,roundtrip.rta1,roundtrip.rta2 (default: all)
- `--kicad-cli PATH`: the kicad-cli to run (unused for Altium input)
- `--timeout SECONDS` (number, default `300.0`): kicad-cli timeout (300; unused for Altium input)
- `--exclude CODE:ITEM_A:ITEM_B`: store a KiCad DRC exclusion of this finding in the project (both item orders) instead of checking; needs --reason and the mutation protocol (KiCad input only)
- `--reason TEXT`: with --exclude: the comment stored with it
- `--matrix`: add result.matrix: the requirement rows of circuit.rules and roles.rules with their status, digest and a receipt of the inputs (read-only; without --stages only those two stages run)
- `--compare-native REPORT`: Altium input: compare the findings with Altium's own DRC (the violations the PCB document stores, or those of a .drc text report); adds result.native and the stages silk.clearance and altium.native-drc
- `--explain-rules`: add result.rules with governing and overridden rules per subject and kind; runs no extra tool

## convert

`fenolite convert [OPTIONS] --to {altium,kicad} --out DIR SRC`

- `SRC`: a KiCad project, board or folder
- `--to {altium,kicad}`: the target backend
- `--out DIR`: the target folder (not the source's)
- `--name NAME`: the file stem
- `--altium-bodies {extruded,off}` (default `extruded`): Altium bodies: extruded (default) or none
- `--altium-pour {computed,outline}`: Altium polygons: computed pours them with Altium's rules (default, experimental; needs the geo extra, without which the conversion exits 6), outline writes them unpoured; a usage error with --to kicad
- `--report-ids`: list item ids in the report
- `--no-verify`: skip the read-back (evidence UNVERIFIED)

## copper

`fenolite copper [OPTIONS] PATH`

- `PATH`: a .kicad_pcb, a .kicad_pro or a built project folder
- `--roles FILE`: the role document to read
- `--requirements FILE`: your distance and current rows
- `--kinds KIND,KIND`: of power,switch_node,ground,high_voltage
- `--net GLOB` (repeatable): only these nets (repeatable)
- `--layers KIND=L,L` (repeatable): the layers of a kind (repeatable)
- `--ground-layers L,L`: the layers of the ground planes
- `--ground-fill {all,reference}`: all: pour the outer area too
- `--connection KIND=MODE` (repeatable): the pad connection of a kind, MODE of solid,thermal,thru_hole_only,none (repeatable)
- `--stitch-pitch LENGTH`: the ground stitching pitch
- `--temp-rise KELVIN`: size by the fit of S-0269
- `--widen PERMILLE`: how far power copper widens
- `--no-corridors`: write no provisional corridor
- `--regenerate KEY` (repeatable): generate this edited role item again (repeatable)
- `--gate {drc}`: drc: judge the edit with kicad-cli DRC and write it without the items that bring new findings
- `--kicad-cli PATH`: kicad-cli binary or docker:<image> for --gate
- `--timeout SECONDS` (number, default `300.0`): per kicad-cli run

## diff

`fenolite diff [OPTIONS] A B`

- `A`: a board, schematic, footprint file, symbol library, built project or Altium file
- `B`: the input to compare with A
- `--view {model,records,tree}` (default `model`): model entities (default), the trees of two KiCad files, or the records of two Altium files
- `--ext`: also compare the opaque content, as a hash
- `--allow KINDS`: comma-separated change kinds (track,via,...); a change of any other kind is an error (exit 5)
- `--three-way THEIRS`: a third KiCad board: write it with the changes from A to B applied (needs --out)
- `--out FILE`: the merged board of --three-way
