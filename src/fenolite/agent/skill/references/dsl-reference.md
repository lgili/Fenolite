# The names of the design script

This page is generated by `tools/gen_agent_guide.py`: do not edit it, change the code and run the tool.

Every name is imported from `fenolite.dsl`. The methods of a class (`Design.board`, `Part.place`,
`Design.track` and the others) are taught by the written pages; `docs/dsl.md` of the source
repository is the full reference.

## Design

Class: `Design(name: 'str') -> 'None'`

A design; its name becomes the KiCad file stem.

## DiffPair

Class: `DiffPair(p: 'Net', n: 'Net', *, name: 'str \| None' = None) -> 'None'`

A differential pair: `p` and `n` nets; the default name is `<p>/<n>`.

## Footprint

Class: `Footprint(library: 'str', name: 'str', *, kind: 'FootprintKind' = 'unspecified', description: 'str' = '') -> 'None'`

Author a library footprint with DSL lengths (`mm()`, `mil()`, `nm()` or unit strings).

## Harness

Class: `Harness(name: 'str', members: 'Mapping[str, Net]') -> 'None'`

A named group of nets with different names, such as SPI with MOSI, MISO and SCK.

## I2C

Class: `I2C(sda: 'Net', scl: 'Net', *, name: 'str \| None' = None) -> 'None'`

An I2C bus: `sda` and `scl` nets; the default name is `<sda>/<scl>`.

## Interface

Class: `Interface(name: 'str', kind: 'str', members: 'Mapping[str, Net]') -> 'None'`

A typed bundle of nets: role → net.

## Module

Class: `Module(name: 'str') -> 'None'`

A named group; its path is its name at the top and `<parent path>/<name>` below.

## Net

Class: `Net(name: 'str') -> 'None'`

A net, named globally and literally; a module-local net is named by the script.

## Part

Class: `Part(ref: 'str', lib_id: 'str', footprint: 'str \| None' = None, value: 'str \| Quantity' = '', *, properties: 'Mapping[str, str] \| None' = None, pad_map: 'Mapping[str, str \| Sequence[str]] \| None' = None, height: 'object' = None) -> 'None'`

A component: reference, symbol lib id, optional footprint lib id, value and user properties.

## Power

Class: `Power(hv: 'Net', lv: 'Net', *, name: 'str \| None' = None) -> 'None'`

A supply: `hv` and `lv` nets; the default name is `<hv>/<lv>`.

## SPI

Class: `SPI(sck: 'Net', mosi: 'Net', miso: 'Net', *, cs: 'Sequence[Net]' = (), name: 'str \| None' = None) -> 'None'`

An SPI bus: `sck`, `mosi`, `miso` and one `cs<i>` net per chip select, in the order given.

## Symbol

Class: `Symbol(library: 'str', name: 'str', *, reference: 'str', value: 'str' = '', footprint: 'str' = '', description: 'str' = '') -> 'None'`

Author a one-unit symbol.

## UART

Class: `UART(tx: 'Net', rx: 'Net', *, name: 'str \| None' = None) -> 'None'`

A UART link: `tx` and `rx` nets, named from device A (side `a`).

## USB2

Class: `USB2(dp: 'Net', dn: 'Net', *, vbus: 'Net \| None' = None, gnd: 'Net \| None' = None, name: 'str \| None' = None) -> 'None'`

A USB 2.0 port: `dp` and `dn` nets, and `vbus` and `gnd` when given.

## amp

Function: `amp(value: 'int \| Fraction \| str') -> 'Quantity'`

A current in amperes: `amp("500m")`; may be negative.

## arc_to

Function: `arc_to(mid: 'object', end: 'object') -> 'ArcStep'`

An arc from the point of the path element before it through `mid` to `end`, each an `(x, y)` pair of lengths in the frame of `place()` or an anchor; the path continues from `end`.

## connect

Function: `connect(net: 'Net', *pins: 'PinHandle') -> 'Net'`

Join each pin to `net`; one designator of one part on two nets is refused.

## farad

Function: `farad(value: 'int \| Fraction \| str') -> 'Quantity'`

A capacitance: `farad("100n")`.

## henry

Function: `henry(value: 'int \| Fraction \| str') -> 'Quantity'`

An inductance: `henry("4u7")`.

## hertz

Function: `hertz(value: 'int \| Fraction \| str') -> 'Quantity'`

A frequency: `hertz("16M")`.

## inch

Function: `inch(value: 'int \| str \| float') -> 'Length'`

`value` inches.

## mil

Function: `mil(value: 'int \| str \| float') -> 'Length'`

`value` mils (thousandths of an inch).

## mm

Function: `mm(value: 'int \| str \| float') -> 'Length'`

`value` millimetres (`mm(0.1)` is 100 000 nm).

## nm

Function: `nm(value: 'int') -> 'Length'`

`value` nanometres; only an `int` is accepted.

## no_connect

Function: `no_connect(*pins: 'PinHandle') -> 'None'`

Mark each pin as intentionally unconnected; a designator that is on a net is refused.

## ohm

Function: `ohm(value: 'int \| Fraction \| str') -> 'Quantity'`

A resistance: `ohm("4k7")`, `ohm("4.7 kΩ")`, `ohm(4700)`.

## protect

Function: `protect(*, tenting: 'object' = None, covering: 'object' = None, plugging: 'object' = None, capping: 'object' = None, filling: 'object' = None) -> 'ViaProtection'`

How a via is protected.

## second

Function: `second(value: 'int \| Fraction \| str') -> 'Quantity'`

A time: `second("10u")`.

## select

Module.

Selectors of `design.rules.rule()`: which items a design rule holds for.

### select.Select

Class: `select.Select(selector: 'Selector') -> None`

A selector expression; `to_model()` gives the model `Selector`.

### select.area

Function: `select.area(area: 'str \| RuleArea') -> 'Select'`

The items whose copper reaches into a rule area, given by name or as the `RuleArea` of `design.rule_area()`.

### select.item

Function: `select.item(kind: 'str') -> 'Select'`

The items of one kind: `track`, `via`, `pad` or `zone`.

### select.net

Function: `select.net(name: 'str \| Net') -> 'Select'`

The items on a net, given by name or as the `Net` itself.

### select.netclass

Function: `select.netclass(name: 'str') -> 'Select'`

The items on the nets of a net class declared with `design.rules.netclass`.

### select.pair

Function: `select.pair(x: 'Interface \| str') -> 'Select'`

The items on the two nets of a differential pair: a `DiffPair`, a `USB2` or another interface of a pair kind, whose base is taken from its net names; or a base as text, `"*"` for every pair.

### select.ref

Function: `select.ref(name: 'str \| Part') -> 'Select'`

The items of a part (for a courtyard rule, the part's footprint), by reference or as the `Part`.

## shape

Module.

Closed paths for the board outline and its cut-outs: `rect`, `circle` and `slot`.

### shape.RingSpec

Class: `shape.RingSpec(points: 'tuple[Point, ...]', arcs: 'tuple[tuple[int, Point], ...]' = ()) -> None`

One closed ring as a script gave it: its vertices in the written frame (`BOARD_ORIGIN` added) and, for each edge that is an arc, `(edge index, mid)`; edge i joins vertex i to vertex i + 1 (mod n).

### shape.circle

Function: `shape.circle(x: 'object', y: 'object', diameter: 'object') -> 'Path'`

The circle of `diameter` centred on `(x, y)`: the two vertices `(x + r, y)` and `(x − r, y)` joined by the arcs through `(x, y − r)` and `(x, y + r)`.

### shape.closed_ring

Function: `shape.closed_ring(path: 'object', what: 'str') -> 'RingSpec'`

Read one closed path for `what` (the call that takes it), or raise `DslError` naming the call and the index of the element at fault.

### shape.rect

Function: `shape.rect(x: 'object', y: 'object', width: 'object', height: 'object', *, radius: 'object' = None) -> 'Path'`

The rectangle with the corners `(x, y)` and `(x + width, y + height)`, starting at the left end of its top edge and running along the top edge first.

### shape.ring_box

Function: `shape.ring_box(ring: 'RingSpec') -> 'tuple[int, int, int, int]'`

The smallest box that holds the vertices of `ring` and the mid points of its arcs: what a zone declared without an outline takes of the board ring.

### shape.round_root

Function: `shape.round_root(p: 'int', q: 'int') -> 'int'`

`sqrt(p / q)` rounded half to even, for `p >= 0` and `q > 0`, with integer arithmetic.

### shape.slot

Function: `shape.slot(start: 'object', end: 'object', width: 'object') -> 'Path'`

The stadium whose round ends are centred on `start` and `end`, `width` wide: its overall length is `|end − start| + width`.

## stack

Module.

The entries of a stack-up in a design script.

### stack.StackEntry

Class: `stack.StackEntry(kind: 'EntryKind', thickness: 'Nm' = 0, material: 'str' = '', epsilon_r: 'str' = '', loss_tangent: 'str' = '', color: 'str' = '') -> None`

One entry of a script stack-up.

### stack.copper

Function: `stack.copper(thickness: 'object') -> 'StackEntry'`

A copper layer of `thickness` (a DSL length above 0); it takes the next copper name of the board.

### stack.core

Function: `stack.core(thickness: 'object', *, material: 'str' = '', epsilon_r: 'object' = None, loss_tangent: 'object' = None, color: 'str' = '') -> 'StackEntry'`

A core of `thickness` (a DSL length above 0) between two copper layers.

### stack.mask

Function: `stack.mask(thickness: 'object', *, material: 'str' = '', epsilon_r: 'object' = None, loss_tangent: 'object' = None, color: 'str' = '') -> 'StackEntry'`

A solder mask of `thickness` (a DSL length, at least 0).

### stack.prepreg

Function: `stack.prepreg(thickness: 'object', *, material: 'str' = '', epsilon_r: 'object' = None, loss_tangent: 'object' = None, color: 'str' = '') -> 'StackEntry'`

A prepreg sheet, with the arguments of `core`; several in one gap are the sheets of one dielectric.

### stack.preset

Function: `stack.preset(name: 'str') -> 'tuple[StackEntry, ...]'`

The entries of the packaged preset `name`, from the top face of the board to its bottom face, to give to `Design.stackup()` on a board of the preset's copper count; `DslError` listing `PRESETS` for an unknown name.

### stack.silkscreen

Function: `stack.silkscreen(*, color: 'str' = '') -> 'StackEntry'`

A silkscreen, above the top mask or below the bottom one; it has no thickness.

## trace

Function: `trace(layer: 'str', *, refs: 'str \| tuple[str, ...]', width: 'object', gap: 'object' = None) -> 'Trace'`

One layer of an impedance target: `layer` a copper layer name, `refs` one reference layer or a tuple of two, `width` the track width and `gap` the gap between the two tracks of a pair (lengths with a unit, for example `mm(0.2)`).

## via_step

Function: `via_step(x: 'object', y: 'object' = None, *, to: 'str', diameter: 'object' = None, drill: 'object' = None, kind: 'str' = 'through', protection: 'object' = None) -> 'ViaStep'`

A via of `kind` (`through`, `blind`, `buried` or `micro`) at `(x, y)` in the frame of `place()`, or at the one point given first: an `(x, y)` pair or an anchor (`part.at(…)`, `part.pad(…).at(…)`); the track continues on the layer `to`.

## volt

Function: `volt(value: 'int \| Fraction \| str') -> 'Quantity'`

A voltage: `volt("3.3")`; may be negative.

## watt

Function: `watt(value: 'int \| Fraction \| str') -> 'Quantity'`

A power: `watt("250m")`.
