# Demo library (test fixture)

Authored for the Fenolite tests (change c0279). It has the layout of fenolite-library.

Each directory keeps its upstream licence. The licence of the repository's own files (CC0-1.0) does not
cover the items. Items are test and benchmark inputs for Fenolite and starting points for users. No item is
used to train a machine-learning model; any such use would be a separate, public decision.
