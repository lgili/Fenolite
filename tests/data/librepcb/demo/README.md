# Authored LibrePCB subset fixture

Authored for Fenolite as CC0-1.0 test data (c0266). All UUIDs, dimensions and mappings are fictional.
Marker files contain only the format number required by the public format. LICENSE.txt is an original
placeholder, not the public CC0 legal code. Positive unit tests inject its hash; an explicit test proves
the unchanged production gate rejects it. S-1097 documents the public hash without vendoring its text.
No third-party CAD, parser or licence payload is copied.
