# Local library import

Authored for Fenolite (CC0-1.0). The fictional EXB6202 sources and their archive are generated by
`tests/_library_import.py`, with no manufacturer model or third-party fixture.

From this folder, review and confirm an import:

```sh
fenolite library import ../../tests/data/library_import/exb6202.zip --into devices --timestamp 2026-11-01T00:00:00Z --dry-run --json
fenolite library import ../../tests/data/library_import/exb6202.zip --into devices --timestamp 2026-11-01T00:00:00Z --confirm --plan <plan_id> --json
fenolite build design.py --out build --dry-run --json
```

The committed `devices/Imported/EXB6202/` is that import. Every imported record stays `UNVERIFIED`
and not shippable. Even this authored example keeps the importer's conservative `see source terms`
label. A real download remains subject to the source's terms when the project is shared.
