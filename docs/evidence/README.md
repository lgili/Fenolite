# docs/evidence

Where Fenolite keeps the evidence behind its claims.

- `sources.md` — every public source consulted for format knowledge or behaviour (URL, licence of
  the source, what it was used for, date consulted). It is the only place ADRs, proposals and
  format pages cite.
- `../hypotheses.md` — the hypothesis register: each claim that is not yet verified, the test or
  kit request that settles it, and the result. `tests/unit/test_hypotheses_register.py` checks the
  register and every hypothesis id cited in live text; `fenolite.verify` reads it.
- `matrix.md` — the evidence matrix: for each backend package and file kind, the evidence level of
  `detect`, `read`, `write` and the two round trips, the level the register holds for each
  hypothesis behind them, and what every backend module declares. It is generated by
  `tools/gen_evidence_matrix.py` from the declarations in the code and is never edited by hand;
  `tests/unit/test_evidence_matrix_page.py` fails while it is stale. `fenolite capabilities` lists
  the same rows as `result.matrix`.
- `altium-kit/` — the run records of the Altium verification kit (`../altium-kit.md`), one JSON file per
  run: digests, sizes, versions and verdicts, no path and no user name. The archive of a run is a release
  asset; the record names it by digest. `fenolite kit status` lists the records and the stale rows.
- Generated reports of oracle runs are added here by later changes.

## Declaring evidence in a backend module

Every module under `src/fenolite/backends/<name>/` declares its evidence in exactly one of three
forms, and `tests/unit/backends/test_evidence_declared.py` fails for a module with none:

1. it owns a claim about a file format or a tool: a module-level constant such as
   `EVIDENCE = Evidence(Level.INFERRED, hypotheses=("H-K-PCB-READ",))`. Every id is a row of
   `../hypotheses.md` that is not refuted, and the level is never above a row it names (lowest wins;
   `tests/unit/test_evidence_register.py`);
2. its code runs only inside other modules of the package: the comment `# evidence: see pcb, mod`,
   in column 0, with module names below the package;
3. it states nothing about a file format or a tool: the comment `# evidence: none, <reason>`.

A reader or writer of a file kind also gets a cell in the package's `claims.py`, which places
constants in the matrix and states no level itself. An `UNVERIFIED` cell is allowed only for an
operation listed as experimental. After any such change run
`uv run python tools/gen_evidence_matrix.py` and commit `matrix.md`.
