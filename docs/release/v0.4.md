# Release record: v0.4

What the release `0.4.0` ships of v0.4, change by change: what each change ships, the test that proves
it, in which CI job, which of its tasks are still open and why. v0.4 has no acceptance block in
`docs/roadmap.md`: it is three groups of proposals (the agent track c0077 to c0081, board authoring c0096
to c0099, the complex board c0100 to c0120) and the changes written on `v04` after `0.3.0` (c0137, c0140,
c0141, c0145, c0152, c0153). A row says `ships`, `ships with deferred tasks` or `pending`. The verdict at
the end is the maintainer's. `tests/unit/test_release_record_v04.py` keeps this page honest about what
exists.

**The maintainer's decision of 2026-10-08.** Everything that depends on his own tests (KiCad GUI saves
made by him, a run of a real AI agent, checks in Altium Designer) is deferred to the next release;
everything else ships. A task deferred by that decision is named under "Deferred to the next release";
the code of its change ships, and no evidence label is raised for it.
