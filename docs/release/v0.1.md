## Recorded limits

- **Item 1, the forty-part board.** Freerouting closed the 39 nets it was given. The `GND` net is joined
  by the zone, which covers both copper layers, and by two vias that the script declares, one under each
  controller: with the router routing `GND` as tracks, it left 7 connections open (`H-K-REL-LOOP40`).
- **Item 1, the moved footprint.** On a board with zones a moved footprint needs a refill before the
  rebuild, because the build refuses a pad that lies on an old fill. `kicad-cli` 9 cannot refill, so on
  9.0.9 this check runs on the blink only. The check moves the part with `fenolite place`; the move in
  KiCad's editor is the manual check above.
- **Item 1, a rebuild after routing.** On the forty-part board the first rebuild after routing writes the
  script's own vias after the router's: the same items in another order. The recorded project is the one
  after that rebuild, and every later rebuild gives the same bytes.
- **Item 2, corpus round trips.** From `docs/evidence/kicad-rt2.md`: RT0 and RT1 hold on 24 boards, the 21
  readable non-heavy demo boards and the 3 third-party boards. The 2 rows tagged `heavy` are not run in
  CI. One demo file is malformed at its tag and is not round-tripped. RT2 holds on 23 boards and is
  `not judged` on 1, whose DRC report KiCad does not repeat. RT2 on 9.0.9 covers the 5 `rt2-9` rows only.
- **Item 5, schemas.** `schemas/` holds the envelope, error and manifest schemas only, beside the model
  schemas. An envelope names `fenolite.<command>.v0`, and no schema file exists for a command's `result`.
- **Residue scan.** The residue scan of v0.1.0 ran with the public gate only: in CI, in the release
  workflow and over the history. The private gate was not run for v0.1.0.
- **Container refill.** `H-K-CLI-DOCKER` is verified locally only: on 2026-10-04, Docker 28.3.2, the image
  `kicad/kicad:10.0.6@sha256:18693567392b80da435f9fa952ce3a3e534c66eb5a6033f5b9c80aa3b19dd3ec` and the
  local `kicad-cli` 10.0.6 gave equal filled text. No CI job runs `tests/kicad/fill/test_docker_cli.py`.
- **Board outlines.** 3 of the 21 readable non-heavy demo boards do not chain into a closed outline
  without a snapping tolerance, and `place` reports `place.no-outline` on them. `H-G-EDGE-EXACT` and
  `H-G-PLACE-OUTLINE` stay `INFERRED`. The acceptance uses built boards, whose outlines chain.
- **Sign-off.** `tools/dco_exceptions.txt` lists three commits of the main branch without a
  sign-off trailer: two squash merges made with the GitHub button (c0016 and c0039) and the archive commit
  of c0039; every other commit carries one. The maintainer confirmed the three on 2026-10-05, and the
  agents were told to sign every commit and to merge locally.
- **Windows.** The hermetic suites pass on Windows (`H-G-REL-WINDOWS`): 5076 passed and 1287 skipped,
  66 of the skips `posix-only fake tool` (1.0 %), whose fake tools exist only as shell scripts. The
  oracle jobs run KiCad in Linux containers, so on Windows `kicad-cli` itself is not exercised by CI:
  Fenolite finds `kicad-cli.exe` on `PATH` and in KiCad's default install folders, a path that only unit
  tests cover.

## Release build

The artefacts are built from the tagged commit in a clean checkout, never from the working tree: the
release workflow's checkout, a fresh clone of the tag, or a worktree of it. The maintainer's working tree
may hold uncommitted and untracked files, and a local source distribution would pack the untracked ones.

```bash
git worktree add "$TMPDIR/fenolite-v0.1.0" v0.1.0
cd "$TMPDIR/fenolite-v0.1.0"
uv build --out-dir dist
uv build packaging/phenolite --out-dir dist
```

Rehearsal before the version commit, on 2026-10-04 at commit `e1769c6`: a worktree of `HEAD` with an
untracked `stray.txt` in it built `fenolite-0.0.1.dev0-py3-none-any.whl` and `fenolite-0.0.1.dev0.tar.gz`
(and the two files of the alias). The source distribution holds 1027 files and no `stray.txt`: it is built
from an allowlist. The version commit changes only the version in the file names.

History scan, on 2026-10-04 at commit `e1769c6`: `uv run python tools/residue/scan.py --history` read
3442 blobs with the public gate and reported 0 hits; the private gate was not run. The row `v0.1.0` of
`docs/evidence/residue-history.md` holds it.
