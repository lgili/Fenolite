# Verificação dos bits de visibilidade dos pinos (c0148)

1. Abra `pinbits.PrjPcb` no Altium Designer 26 e abra a folha `pinbits.SchDoc`.
2. Há quatro LEDs (D1 a D4) lado a lado, com um texto V1, V2, V3 e V4 acima de cada um. Os pinos são 1 = A e 2 = K.
3. Para cada um (V1 a V4), diga se o **número** do pino (1, 2) e o **nome** do pino (A, K) aparecem no desenho (e, se puder, o que o painel Properties ▸ Pins mostra).
4. Esperado: V1 nenhum dos dois; V2 só o número; V3 só o nome; V4 os dois.
