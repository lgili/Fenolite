# Conferência da correção c0148 no LED (2 min)

O mesmo projeto `flat` do kit, refeito com a correção dos bits de visibilidade dos pinos (commit `c3e15ac`).

1. Abra `flat.PrjPcb` e a folha `flat.SchDoc`.
2. Olhe o LED `D1`. Esperado: **sem** as letras K e A; só os números dos pinos (com o mapa de pads, o Altium mostra o número do pad e o do pino entre parênteses); triângulo apontando para a barra.
3. Os outros símbolos (U1, R1, J1) devem mostrar só o que é para mostrar, sem nomes sobrepostos.

Resposta: "D1 como esperado" ou o que apareceu diferente.
