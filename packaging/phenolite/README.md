# phenolite → Fenolite

`phenolite` is an alias. Installing it installs **[Fenolite](https://github.com/lgili/Fenolite)**,
the headless, agent-first PCB design automation library for Python:

```bash
pip install fenolite      # the real package
pip install phenolite     # the same thing, for those who spell it in English
```

Import `fenolite` in your code. *Fenolite* is the Portuguese word for phenolic board material.
